# 手电钻使用手册（社区共享工具）

## 一、换钻头步骤

1. 断电：更换钻头前务必拔掉电源或取出电池，防止误启动；
2. 松夹头：逆时针旋转夹头环（钥匙式夹头需用配套钥匙插入孔位旋转），直到夹爪张开；
3. 取旧钻头：取出旧钻头，清理夹爪内碎屑；
4. 装新钻头：将钻头柄插入夹头中央，目测居中，顺时针拧紧夹头环，钥匙式需三孔轮流锁紧；
5. 空载试转：装好后空转 2-3 秒，观察钻头无晃动方可使用。

## 二、安全操作警示

- 操作时必须佩戴护目镜，长发请束发并远离钻头；
- 严禁钻穿承重墙内的电线水管区域，作业前请使用墙体探测仪；
- 钻头未完全停止前，不得用手触碰或放置电钻；
- 登高作业时请使用稳定梯具，禁止手持工件悬空钻孔；
- 儿童与宠物请保持在 2 米以外。

## 三、保养与参数

- 本型号手电钻最大钻孔直径：木材 25mm、钢材 10mm、混凝土 8mm；
- 功率 550W，额定电压 220V，空载转速 0-3000 转/分钟可调；
- 每次归还前请清理机身与散热孔粉尘；碳刷磨损至 5mm 以下应报修更换；
- 长期存放请置于干燥工具柜，电池型号每三个月充放电一次。

## 四、租赁规则摘要

- 押金 200 元，归还验收完好后原路退还；
- 取件时请携带身份证或预约单号，逾期按每小时 5 元计费，封顶为押金金额；
- 归还时由社区工作人员现场验收，损坏按损坏程度扣除部分或全部押金。
