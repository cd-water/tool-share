## 4. 启动与初始化

### 4.1 启动中间件

```bash
cp ops/.env.example ops/.env
cd ops && docker compose up -d && cd ..
# 首次会拉取 bge-m3；没有它 AI 检索会降级，不影响主流程
```

### 4.2 启动后端

```bash
set -a; source ops/.env; set +a
./mvnw spring-boot:run
```

后端启动时自动执行：

1. Flyway 建表；
2. 空库时执行 `seed/demo-data.sql`；
3. 导入 `seed/knowledge/` 下 28 篇知识库文档；
4. 上传 `seed/images/` 下工具图片、头像与登录背景；
5. 设置 MinIO 公开读策略并回填图片直链；
6. 建立知识库与工具向量索引；
7. 校准 Redis 单号序列。

### 4.3 启动前端

居民端：

```bash
cd frontend/web && pnpm install && pnpm dev
```

管理端：

```bash
cd frontend/admin && pnpm install && pnpm dev
```

## 6. 验证方式

### 6.1 一键验证

```bash
bash ops/verify.sh
```

执行内容：

1. 后端编译；
2. 后端测试（Testcontainers 启动 MySQL/Redis）；
3. 居民端 lint 与构建；
4. 管理端构建；
5. 三条 Playwright 主流程 E2E。

跳过 E2E：

```bash
SKIP_E2E=1 bash ops/verify.sh
```

执行前确保 `8900/5901/5902` 端口空闲，中间件已启动，`ops/.env` 存在。

### 6.2 AI 评测

```bash
bash ops/ai-eval.sh
```

输出检索命中率与引用准确率，默认阈值 0.8。评测不进入 `ops/verify.sh` 默认门禁。

## 8. 配置与部署注意事项

### 8.1 关键环境变量

| 变量 | 说明 |
| --- | --- |
| `ID_CARD_AES_KEY` | 16/24/32 字节，必填；生产必须替换示例值 |
| `MINIO_ENDPOINT` | 后端 S3 客户端地址 |
| `MINIO_PUBLIC_ENDPOINT` | 浏览器直连对象地址；生产必须为公开域名或反向代理 |
| `DEEPSEEK_API_KEY` | 留空时 AI 降级，不影响主流程 |
| `QDRANT_API_KEY` | Qdrant 访问密钥 |
| `MYSQL_ROOT_PASSWORD` / `REDIS_PASSWORD` | 中间件凭据 |

完整清单见 `ops/README.md`。

### 8.2 部署边界

- **单实例假设**：`@Scheduled` 提醒、Redis 提醒队列与蹲守集合不适用于多副本。
- **无 CI/CD**：合并门禁为本地 `bash ops/verify.sh` 全绿。
- **公开桶**：工具图片、头像与报修照片可被知道 URL 的人读取；敏感场景应升级私有桶 + 签名 URL。
- **生产反向代理**：两个前端 `dist/` 由静态服务器托管，`/api` 代理到 `:8900`；SSE 需关闭代理缓冲。
- **备份**：MySQL 与 MinIO 为必须备份的数据源；Redis 会话可重建；Qdrant 索引与 Ollama 模型可重建。

## 9. 已知限制

1. 验证码短信为 Mock，不会发送真实短信。
2. 支付为沙箱/演示流程，不对接真实支付渠道。
3. 所有对象在公开桶中，报修照片与头像不具备访问控制。
4. 定时任务按单实例设计，不支持多副本。
5. 未接入居民信息系统、视频报修与管理员操作审计表。
6. AI 依赖外部模型与本地向量服务；服务不可用时返回兜底内容。
7. 未维护 CI/CD 流水线，验证依赖本地脚本。
