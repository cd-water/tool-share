## 1. 工具信息录入单

### (1) 模板

| 类别 | 字段名称 | 字段说明 | 数据类型 | 是否必填 | 填写规则/选项示例 |
| --- | --- | --- | --- | --- | --- |
| 基础标识信息 | 工具编码 | 系统自动生成，唯一标识工具 | 文本 | 否（自动） | 格式：SQ-G-XX-YYYY，其中：<br>SQ=社区缩写<br>G=工具<br>XX=类别（WX=维修/YY=园艺/QJ=清洁）<br>YYYY=4 位序号 |
|  | 工具名称 | 工具通用名称 | 文本 | 是 |  |
|  | 工具型号规格 | 工具具体型号（含品牌、尺寸等参数） | 文本 | 是 |  |
| 详细属性信息 | 工具类别 | 工具所属分类，关联标签管理 | 文本 | 是 | □维修工具 □园艺工具 □清洁工具 □其他（需注明） |
|  | 初始损坏程度 | 工具录入时的实际损耗状态 | 文本 | 是 | □全新 □轻微磨损（无功能影响） □中度磨损（外观瑕疵，功能正常） □严重损坏（需维修后使用） |
|  | 押金金额 | 按工具价值设定的租赁押金 | 数值 | 是 | 标注"元" |
|  | 存放区域 | 工具在社区内的具体存放位置 | 文本 | 是 | 格式："社区服务站+柜体编号" |
|  | 使用说明 | 工具操作步骤、注意事项（支持图文） | 富文本 | 是 | 文字：分点说明操作流程；<br>图片：上传工具操作示意图/安全警示图（可选） |
| 附加管理信息 | 工具图片 | 工具实物照片（正面、侧面） | 图片文件 | 否 | 支持 JPG/PNG 格式，单张大小≤5MB |
|  | 采购日期 | 社区采购该工具的日期（便于计算使用年限） | 日期 | 否 | 格式："YYYY 年 MM 月 DD 日" |
|  | 供应商信息 | 工具采购供应商名称及联系方式 | 文本 | 否 |  |
| 录入审核信息 | 录入人 | 负责录入工具信息的社区工作人员姓名 | 文本 | 是 |  |
|  | 录入时间 | 信息录入系统的时间 | 日期时间 | 否（自动） | 格式："YYYY 年 MM 月 DD 日 HH:MM" |
|  | 审核状态 | 工具信息是否通过审核 | 下拉选择 | 是 | □待审核 □已通过 □需修改（修改意见：______） |

## 2. 租赁记录单

### (1) 模板

| 类别 | 字段名称 | 字段说明 | 数据类型 | 是否必填 | 填写规则/选项示例 |
| --- | --- | --- | --- | --- | --- |
| 基础标识信息 | 租赁预约单号 | 关联租赁预约模块，唯一标识本次租赁业务 | 文本 | 是（自动） | 格式：SQ-ZY-YYYYMMDD-XXXX，其中：<br>SQ=社区缩写<br>ZY=租赁<br>YYYYMMDD=预约日期<br>XXXX=4 位流水号 |
|  | 工具编号 | 关联工具信息模块，对应租赁工具的唯一编码 | 文本 | 是（关联） | 格式：SQ-G-XX-YYYY |
|  | 工具名称 | 关联工具编号自动带出 | 文本 | 是（关联） |  |
| 租赁人信息 | 租赁人姓名 | 租赁工具的居民姓名 | 文本 | 是 |  |
|  | 租赁人联系方式 | 居民备案手机号 | 文本 | 是 | 脱敏显示 |
|  | 租赁人身份证号 | 居民身份标识 | 文本 | 是 | 脱敏显示 |
| 租赁时段与取件信息 | 租赁开始日期时间 | 约定的使用起始时间 | 日期时间 | 是 | 格式："YYYY 年 MM 月 DD 日 HH:MM" |
|  | 租赁结束日期时间 | 约定的使用截止时间 | 日期时间 | 是 | 格式同租赁开始时间 |
|  | 取件人 | 实际领取工具的人员 | 文本 | 是 | 填写取件人姓名，本人或代取人 |
| 押金与费用信息 | 押金金额 | 按工具预设金额填写 | 数值 | 是（关联） | 整数，需标注"元" |
|  | 逾期费用 | 按社区规则计算 | 数值 | 否 | 归还后补充；最高不超过押金总额；无逾期则填"0" |
|  | 押金退还金额 | 实际退还金额 | 数值 | 否 | 归还后补充；扣除逾期费用/损坏赔偿，无扣除则等于押金金额 |
| 归还验收信息 | 归还时间 | 居民实际归还工具的时间 | 日期时间 | 否 | 归还后补充；工作人员验收时填写，格式同租赁开始时间 |
|  | 验收结果 | 对工具的损耗状态评估 | 文本 | 否 | □完好（无新增损坏） □轻微损坏（不影响功能，无需赔偿） □严重损坏（影响功能，需赔偿） |
|  | 逾期情况 | 是否逾期及逾期时长 | 文本 | 否 | 无逾期则填"无" |
| 记录管理信息 | 录入人 | 录入的工作人员姓名 | 文本 | 是 | 填写工作人员真实姓名 |
|  | 录入时间 | 租赁记录生成的时间 | 日期时间 | 是 | 格式："YYYY 年 MM 月 DD 日 HH:MM" |
|  | 更新人 | 补充的工作人员姓名 | 文本 | 否 | 归还后补充；填写工作人员真实姓名 |
|  | 更新时间 | 记录更新记录的时间 | 日期时间 | 否 | 格式："YYYY 年 MM 月 DD 日 HH:MM" |

## 3. 损坏报修单

### (1) 模板

|  | 维修进度状态 | 维修任务的实时进展 | 文本 | ①待配件 ②维修中 ③维修完成 ④维修失败（需报废） |
|  | 进度更新时间 | 每次修改维修进度的时间 | 日期时间 | 格式：YYYY-MM-DD HH:MM |
|  | 进度更新说明 | 进度变更的原因 | 文本 | 进度变更时必填 |

|  | 备注 | 费用分摊、赔偿等说明 | 文本 |  |
