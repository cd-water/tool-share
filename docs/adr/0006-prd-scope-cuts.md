# PRD 范围裁剪

以下 PRD 条目经评估后不做正式实现，理由记录于此，避免评审误判为遗漏：

- **财务数据字段级加密**：由部署层 HTTPS 承担传输安全，应用不做字段级加密。
- **数据库备份策略**：作为部署说明项写入运维文档，不写代码。
- **居民信息系统对接**：PRD 标为可选项，明确不做。
- **视频报修**：附录仅要求 1–3 张图片，不支持视频。

以下条目虽在初版中缺失或形式实现，但纳入重构范围：可预约时段前端接入、验收结果筛选、居民按单号检索、维修完成通知工作人员、工具历史租赁关联、身份证脱敏快照与录入/更新人、归还时间填写、工具录入审核工作流、提醒送达状态与 Mock 短信通道、三级权限。
