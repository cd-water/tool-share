# 手推式割草机安全操作

## 适用工具

手推式割草机适用于社区绿地、庭院草坪修剪，例如本田 GX35。使用前应确认草坪内没有石块、树枝、铁丝、玩具等杂物。

## 使用前检查

1. 检查机油油位，四冲程发动机使用汽油，不要随意混入机油。
2. 检查刀片是否松动、变形或严重磨损，防护罩是否齐全。
3. 检查油门、熄火开关和离合机构是否正常。
4. 加注燃油时发动机必须冷却，远离明火，不要在室内加油。
5. 佩戴护目镜、防滑鞋和长裤，不要穿拖鞋或宽松裤脚。

## 操作要点

1. 在平坦地面启动，启动时不要站在刀片正前方。
2. 双手握紧扶手，保持稳定推进，不要跑动。
3. 坡地作业应横向或斜向行进，不要在陡坡上上下直推；坡度较大时停止使用。
4. 遇到异物立即熄火，待刀片完全停止后再清理。
5. 不要在湿滑草地上作业，避免打滑和排草口堵塞。
6. 清理排草口、调整高度或搬动机器前必须熄火并拔下火花塞帽。
7. 儿童和宠物应远离作业区域。

## 使用后

熄火并等待机器冷却，清理刀盘和机身上的草屑，检查刀片和螺丝。存放在干燥通风处，避免雨淋。发现刀片弯曲、发动机异响、漏油或启动困难，停止使用并报修。
