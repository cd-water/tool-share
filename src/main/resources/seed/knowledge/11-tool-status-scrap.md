# 工具停用、维修与报废规则

## 工具状态

系统中的工具状态包括：

- 可预约：审核通过、状态正常，可以创建租赁单；
- 租赁中：已被居民取走，正在使用；
- 维修中：因故障或损坏暂停使用，等待维修或验收；
- 已报废：无法修复或维修成本过高，不再流通。

## 停用

发现以下情况应先将工具停用：漏电、冒烟、异响、外壳开裂、防护装置缺失、刀片或钻头严重磨损、结构变形、进水或跌落后的工具。停用后不得被预约，工作人员应在系统中选择停用原因并备注。

## 维修

维修由具备相应能力的人员进行。维修前确认故障原因，维修后必须进行功能和安全检查。更换关键安全部件时，应使用符合规格的配件，不得用非标零件代替。

## 恢复使用

维修完成并验收合格后，工作人员将工具状态改回可预约。恢复前应确认：

1. 故障已排除；
2. 防护装置齐全有效；
3. 配件完整；
4. 清洁状况合格；
5. 审核状态有效。

## 报废

出现以下情况可申请报废：机身或关键结构无法修复、维修成本接近或超过残值、缺少关键安全部件且无法采购、多次维修仍反复故障。报废需经管理人员确认，并在台账中记录原因和时间。报废工具不得再次上架或转卖。

## 责任

因未及时停用故障工具导致居民受伤或损失扩大的，追究相关工作人员责任。
