# 紧急情况处置与急救

## 触电

1. 立即切断电源；无法断电时，用干燥木棍、绝缘工具挑开电源线。
2. 不要直接用手拉触电者。
3. 拨打 120，检查呼吸和意识；必要时在调度员指导下进行心肺复苏。
4. 报告社区并保留现场，排查工具和线路问题。

## 割伤与出血

1. 停止作业，远离刀片和钻头。
2. 用干净纱布或布料直接压迫伤口止血，抬高受伤部位。
3. 伤口较深、出血不止、有异物或涉及手指关节时，立即就医。
4. 不要用泥土、烟灰或不明药粉敷伤口。

## 异物入眼

1. 不要揉眼。
2. 用清水或生理盐水从内眼角向外冲洗至少 15 分钟。
3. 不要试图自行取出嵌入眼球的异物。
4. 冲洗后仍有疼痛、畏光或视力模糊，立即就医。

## 火灾与冒烟

1. 电动工具冒烟或起火时，先切断电源，不要用水扑救带电设备。
2. 使用干粉或二氧化碳灭火器，火势无法控制时立即撤离并拨打 119。
3. 燃油设备起火时远离油箱，不要贸然搬动。

## 坠落与砸伤

1. 不要随意搬动疑似脊柱或骨折受伤者。
2. 拨打 120，保持伤者体温，等待专业救援。
3. 设置警戒，防止二次坠落或工具掉落伤人。

## 事后报告

任何人身伤害、设备冒烟、漏电、坠落或火灾，都应报告社区服务站，记录时间、工具编号、经过和处理结果，配合排查原因。
