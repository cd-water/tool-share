# 电锤安全操作与墙体管线避让

## 适用场景

电锤用于混凝土、砖墙等坚硬基材的钻孔，例如博世 GBH 2-26。普通木材、金属薄板应使用手电钻，不要用电锤强行作业。

## 使用前

1. 检查电源线、插头、开关和碳刷状态，确认机身无裂纹。
2. 选择与孔径匹配的 SDS 钻头，确认钻头尾部清洁、无变形，插入后拉一下确认锁定。
3. 确认墙体内部管线位置。可使用管线探测仪，或对照房屋图纸；无法确认时先小孔试探，不要直接大力冲击。
4. 佩戴护目镜、防尘口罩和防滑鞋；高处作业时使用稳固平台，不要站在不稳定的凳子上。
5. 确认作业区域下方没有人员，防止碎块坠落。

## 操作要点

1. 双手握持电锤，机身贴紧墙面，先轻触发力，待钻头定位后再持续冲击。
2. 不要用身体重量死压电锤，避免钻头突然穿透时失去平衡。
3. 钻到钢筋时停止冲击，换位置或改用金属钻头，不要强行打断钢筋。
4. 连续作业时间不宜过长，注意机身温度，过热时停机冷却。
5. 更换钻头、清理孔洞前必须拔掉电源。
6. 高空作业时注意电锤重量和反作用力，必要时两人配合。

## 使用后

拔掉电源，清理钻头、机身和孔洞周围的粉尘，检查钻头是否磨损。电锤放回工具箱，避免受潮。发现冲击无力、异响、漏电或外壳过热，停止使用并报修。
