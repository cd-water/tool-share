# 家用工具箱使用与清点

## 工具组成

家用工具箱通常包含螺丝刀、扳手、锤子、钳子、卷尺、内六角等常用手工工具，例如史丹利 65 件套。不同套装的件数可能不同，借用前应确认清单。

## 借用前清点

1. 打开工具箱，对照清单核对工具种类和数量。
2. 检查螺丝刀刀头、钳口、锤头是否完好，手柄是否开裂。
3. 检查卷尺回弹是否正常，扳手是否有严重锈蚀。
4. 发现缺件或损坏，当场向工作人员说明并拍照，不要带走后自行补配。

## 使用注意

1. 选择与螺丝规格匹配的刀头，避免滑牙和刀头崩裂。
2. 扳手不要加套管加力，防止扳手断裂或螺母损坏。
3. 锤子使用前检查锤头是否松动，挥锤方向不要站人。
4. 不要把螺丝刀当撬棍或冲子使用，不要用钳子代替扳手。
5. 使用后擦净油污和水分，防止生锈。
6. 工具不是玩具，儿童不得单独使用。

## 归还前

按原位置放回工具箱，逐件清点，确认没有遗留在作业现场。清理箱内灰尘和杂物，检查是否有损坏或缺失。归还时与工作人员共同清点，确认无误后办理验收。
