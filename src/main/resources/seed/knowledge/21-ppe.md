# 个人防护装备使用指南

## 常用防护装备

- 护目镜：钻孔、切割、修剪、清洗和吹扫时防止碎屑、粉尘和液体飞溅。
- 防尘口罩：钻孔、打磨、清扫和割草时减少粉尘吸入。
- 防割手套：搬运玻璃、金属件和修剪枝条时保护双手。
- 防滑鞋：户外、湿滑地面和高处作业时防止滑倒。
- 耳塞或耳罩：长时间使用高噪声设备时保护听力。
- 长裤和紧身袖口：减少割伤、擦伤和卷入风险。

## 选择与检查

1. 防护装备应合身，不影响视线和操作。
2. 护目镜镜片应清晰、无裂纹，松紧带有效。
3. 防尘口罩应贴合面部，发现破损、潮湿或呼吸阻力明显增大时更换。
4. 防割手套应无破洞；操作台钻、电钻等旋转设备时不要戴宽松手套。
5. 防滑鞋鞋底花纹应清晰，鞋带系紧。

## 使用原则

1. 进入作业区域前穿戴好防护装备，不要等开始操作后才戴。
2. 不要用普通眼镜代替护目镜，不要用围巾或口罩代替防尘口罩。
3. 防护装备不能替代安全操作，仍要保持专注、控制力度和确认周围人员。
4. 使用后清洁防护装备，存放在干燥处；一次性口罩不要重复使用。

## 社区提供与自备

社区服务站可提供部分公用防护装备，数量有限。建议居民自备合身的护目镜、口罩和防滑鞋。公用装备归还前应清洁消毒。
