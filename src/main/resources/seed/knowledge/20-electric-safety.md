# 电动工具用电安全

## 电源与线路

1. 使用带漏电保护装置的插座，定期按试验按钮检查保护功能。
2. 延长线应有足够截面积和额定电流，不要多根串联或一盘到底长时间使用。
3. 电源线不要压在门下、泡在水里或被重物碾压；发现破损立即停用。
4. 不要私自改装插头、拆除接地线或使用无接地的转换头。
5. 电动工具应使用与铭牌一致的电压，不要接入不明电源。

## 作业环境

1. 潮湿环境、户外雨天和积水区域不使用普通电动工具。
2. 作业区域保持干燥、通风，远离易燃物和可燃气体。
3. 电动工具不要靠近易燃粉尘、油漆稀释剂和燃气管道。
4. 高空作业时注意电源线长度，避免绊倒和拉拽。

## 操作习惯

1. 插电前确认开关处于关闭状态，避免通电瞬间意外启动。
2. 更换钻头、刀片、吸头、软管或清理堵塞前，必须拔掉电源。
3. 不要用手制动旋转中的部件，不要超负荷使用。
4. 发现麻手、漏电、冒烟、焦味、异响或火花异常，立即断电并报修。
5. 离开作业现场或长时间不使用时，拔掉电源。

## 触电处置

发现有人触电，先切断电源或用绝缘物挑开电源线，不要直接用手拉人。立即拨打 120，并在确保安全的前提下进行急救。事后应报告社区并排查设备。
