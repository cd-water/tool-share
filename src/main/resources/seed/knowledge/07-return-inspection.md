# 归还验收标准与损坏判定

## 验收内容

工作人员在居民归还工具时进行现场验收，主要包括：

1. 外观：外壳、手柄、电源线、刀片、钻头夹头等是否有裂纹、变形、烧灼或明显磨损。
2. 功能：通电试运行、开关、调速、制动、吸力、水压等是否正常。
3. 配件：说明书、充电器、电池、工具箱、喷枪、软管、梯子卡扣等是否齐全。
4. 清洁：是否清除灰尘、油污、草屑和积水，是否影响下一位居民使用。

## 损坏程度

系统将工具损坏程度分为四级：

- 全新：无明显使用痕迹或仅有正常轻微磨损。
- 轻微：不影响安全和主要功能的小损伤，如外壳轻微划痕、配件松动。
- 中等：影响部分功能或需要更换零件，如刀片变钝、软管破损、开关接触不良。
- 严重：影响安全使用或主要功能失效，如电机烧毁、机身开裂、结构变形。

## 赔偿原则

1. 正常磨损不收取赔偿。
2. 因使用不当、跌落、进水、超负荷等造成的损坏，按维修成本和损坏程度确定赔偿。
3. 可维修的优先维修；无法维修或维修成本过高的，按工具折旧后的价值协商赔偿。
4. 赔偿从押金中扣除，超出押金的部分另行结算。
5. 对判定有异议时，工作人员应拍照记录并提交复核，居民可保留证据。

## 验收结果

验收完成后，租赁单记录损坏结果、逾期费、损坏赔偿、减免金额和退款金额。居民可在租赁单详情中查看费用明细和支付流水。
