# 工具清洁、消毒与归还前检查

## 归还前清洁

1. 清除工具表面的泥土、灰尘、草屑、木屑、油污和水渍。
2. 清洗机、割草机和吸尘器应排空水箱、油箱、尘盒和软管。
3. 修枝剪、刀具等锋利部件擦干后涂薄层防锈油。
4. 梯子、工具箱和配件擦拭干净，避免把污染物带回服务站。
5. 不要用水直接冲洗电机、电池、开关和电气接口。

## 消毒

共用工具的手柄、开关、扶手、梯子和防护装备在归还后应使用合适的消毒湿巾或稀释消毒液擦拭，作用时间按产品说明执行。消毒后擦干，避免消毒液残留腐蚀金属或刺激下一位使用者皮肤。

## 归还前检查

1. 对照借用清单清点配件，确认没有缺失。
2. 检查工具外观和功能，确认没有新增损坏。
3. 检查电源线、软管、刀片、钻头和卡扣是否完好。
4. 确认工具已清洁、干燥，可以安全存放。
5. 如发现损坏或缺失，主动向工作人员说明并提交报修或补配记录。

## 存放

工具应存放在干燥、通风、儿童接触不到的位置。电池工具远离高温和易燃物；燃油设备远离火源；锋利工具加保护套；梯子平放或靠稳，避免倾倒。
