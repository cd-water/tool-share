# 老年人与未成年人使用规范

## 未成年人

1. 未满 18 周岁的居民借用工具，应由监护人陪同并同意。
2. 未成年人不得单独操作电钻、电锤、割草机、高压清洗机、修枝剪等高风险工具。
3. 监护人应全程在场，确认工具、防护装备和作业环境安全。
4. 不得让儿童在作业区域玩耍，工具和配件应放在儿童接触不到的位置。
5. 学校或社区组织的青少年工具体验活动，应在工作人员指导下进行。

## 老年人

1. 老年居民借用工具前应评估体力、视力和平衡能力，选择重量轻、操作简单的工具。
2. 搬运重物、登高和长时间弯腰作业时，建议家人或工作人员协助。
3. 使用梯子、割草机和电动工具时，确保有人在附近，避免独自在封闭或偏远区域作业。
4. 服用可能影响注意力或平衡的药物后，不要操作电动工具或登高。
5. 出现头晕、胸闷、乏力等不适，立即停止作业并求助。

## 工作人员职责

1. 对老年人、未成年人或行动不便者，主动说明工具风险和安全要点。
2. 发现借用者状态不适合操作时，有权建议更换工具、由他人陪同或暂缓借用。
3. 取件时确认取件人身份，必要时联系监护人或家属。
4. 对高风险工具做好重点提示，并记录已告知安全事项。

## 共同原则

工具共享的前提是安全。任何年龄的居民都应在自己能力范围内使用工具，不逞强、不冒险、不隐瞒身体不适。遇到不确定的情况，先咨询社区工作人员。
