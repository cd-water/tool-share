# 折叠梯安全使用规范

## 使用前检查

1. 检查梯子铰链、卡扣、拉杆和踏板是否完好，展开后卡扣必须锁定。
2. 检查防滑脚垫是否磨损、缺失，梯脚是否变形。
3. 检查梯身有无裂纹、弯曲或严重锈蚀。
4. 确认地面平整、干燥、坚固，不要放在松土、油污或湿滑地面上。

## 正确使用

1. 展开到最大角度并确认锁定，必要时请他人扶稳。
2. 面向梯子上下，双手扶稳，保持三点接触；不要背对梯子或跳跃下来。
3. 不要站在最高两阶作业，身体重心保持在梯子两侧支柱之间。
4. 不要过度伸手或侧身，需要移动时先下梯再移动。
5. 梯子上只允许一人作业，不要两人同时攀爬。
6. 金属梯不要靠近电线、配电箱和高压设备；必要时使用绝缘梯或请专业人员处理。
7. 穿防滑鞋，不要穿拖鞋、高跟鞋或宽松裤脚。

## 使用后

收起梯子前确认无人站在上面，清理泥土和水分，检查卡扣和脚垫。折叠后放在干燥处，不要靠在不稳定的墙边或通道上。发现卡扣失效、梯脚缺失或结构变形，停止使用并报修。

## 提醒

梯子只能用于登高取物、简单安装等轻量作业。需要长时间高处作业或涉及电气、外墙施工时，应联系专业人员，不要自行冒险。
