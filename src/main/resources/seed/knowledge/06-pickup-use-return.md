# 取件、使用与归还流程

## 取件前

1. 确认租赁单状态为“已预约”，押金已支付。
2. 按预约时间到达社区服务站，携带能够证明身份的证件。
3. 取件人应与租赁单登记的取件人一致；如需他人代取，请提前联系工作人员。

## 现场取件

工作人员核对租赁单号和取件人信息后，会与居民一起检查工具外观、配件和功能。确认无误后完成取件，租赁单状态变为“使用中”。发现工具已有损坏或缺少配件时，请当场提出并拍照留存，不要直接带走。

## 使用期间

1. 按工具说明书和安全指引操作，佩戴必要的防护用品。
2. 工具仅限在登记的用途和场所使用，不得转借他人。
3. 妥善保管工具和配件，避免雨淋、跌落和超负荷使用。
4. 发现异常声音、异味、冒烟或功能失灵，立即停止使用并联系社区，不要自行拆修。
5. 需要延期时请提前联系工作人员；系统不提供自动续借，逾期会产生逾期费。

## 归还

1. 在预约结束时间前将工具送回社区服务站。
2. 归还前清理灰尘、油污和杂物，清点全部配件。
3. 工作人员进行归还验收，检查外观、功能、配件和清洁情况。
4. 验收完成后结算逾期费、损坏赔偿和押金退款。
5. 如存在未处理完的报修单，系统可能阻止直接归还，请先配合工作人员完成核验。

## 逾期归还

逾期归还会产生逾期费。请尽快归还并说明原因；因不可抗力无法按时归还的，及时联系社区，工作人员可视情况协助处理。
