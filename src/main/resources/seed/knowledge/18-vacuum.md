# 吸尘器使用与滤网清洁

## 适用工具

吸尘器用于清理地面、家具和车内灰尘，例如戴森 V8。不要吸取液体、易燃易爆粉尘、建筑垃圾、尖锐金属和高温灰烬。

## 使用前检查

1. 检查电量是否充足，电池和充电器是否完好。
2. 检查尘盒是否已清空，滤网是否干燥、安装到位。
3. 检查吸头和延长杆是否堵塞，连接是否牢固。
4. 检查机身外壳和开关是否破损。

## 使用要点

1. 根据地面选择吸头：硬质地面用软绒滚刷，缝隙用窄缝吸头，家具用软毛刷。
2. 吸头不要长时间贴住地毯或窗帘，避免吸力过大导致电机过热。
3. 吸取大颗粒或毛发时注意堵塞，发现吸力明显下降应停机检查。
4. 不要吸取水、油、潮湿污物和未熄灭的烟头。
5. 清理楼梯和高处时注意站稳，不要过度伸手。
6. 使用后及时清空尘盒，避免异味和细菌滋生。

## 清洁与保养

1. 按说明书拆下滤网，用清水冲洗后完全晾干再装回，未干透的滤网会损坏电机。
2. 清理滚刷上的毛发和缠绕物，检查刷毛是否变形。
3. 用湿布擦拭机身，不要用水冲洗电机部分。
4. 电池避免暴晒和高温，长期不用时保持适量电量。
5. 发现吸力弱、异响、发热或电池鼓包，停止使用并报修。
