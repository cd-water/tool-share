# 损坏报修居民操作指南

## 什么时候报修

使用工具过程中发生以下情况，应立即停止使用并提交报修：

- 工具无法启动、频繁断电或开关失灵；
- 电机异响、冒烟、焦味或机身过热；
- 刀片、钻头、软管、喷枪等部件损坏；
- 外壳开裂、漏电、漏水或结构变形；
- 因跌落、进水、碰撞等造成损坏。

## 提交报修

1. 进入居民端“报修”页面，选择对应的租赁单。
2. 填写损坏部位、损坏经过和当前状态。
3. 上传能看清损坏位置的照片，照片应包含整体和局部。
4. 提交后生成报修单，状态为“已提交”。

## 报修后

工作人员会核验报修内容，可能通过电话联系补充信息。核验结果可能是“确认损坏”或“驳回”。确认后进入维修流程，维修完成后由工作人员验收，并决定工具恢复使用、继续维修或报废。

## 注意事项

1. 不要自行拆解工具或更换零件，避免扩大损坏和影响责任判定。
2. 不要隐瞒损坏继续使用，带故障使用可能造成人身伤害。
3. 存在未处理完的报修单时，系统可能阻止直接归还，请先联系工作人员。
4. 报修单和照片是验收与赔偿的重要依据，请如实填写。
5. 对核验或赔偿结果有异议时，联系社区工作人员复核。
